## How to use

- Download: Click any image above (or browse the repository) and click "Download" on GitHub, or right-click and "Save image as..." to save locally.
- Set as wallpaper: On most operating systems you can right-click the saved image and choose "Set as desktop background" or change it in your system settings.
- Resize: Many images in this collection are high-resolution; resize or crop them as needed for your display.

## About

This repo is a personal collection of backgrounds gathered from various sources. Some are photographs, some are digital art or AI-generated images, and some are stylized wallpapers.

If you recognize any images that require attribution or have a license restriction, please open an issue or submit a PR and I'll update the README and file metadata accordingly.

## Contributing

- Want to add backgrounds? Submit a pull request with your image(s) added to the root of the repository or in a new folder. Include source/attribution in the PR description if available.
- Report issues: If a file is broken or incorrectly named, open an issue describing the problem.
